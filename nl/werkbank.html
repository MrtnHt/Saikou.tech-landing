Kijk wat een fix veranderde, niet wat hij beweert.

Mechanische patroonchecks, als JavaScript in je browser. De checks op gevaarlijke patronen zijn geschreven voor Python; de checks op onderdrukkingen dekken ook JavaScript/TypeScript, Java en C#. Geen syntaxboom, geen externe analyzer, geen server: wat je plakt, wordt nergens heen gestuurd.

Plak de code

Zet de oorspronkelijke code in Voor en de gewijzigde code in Na, en klik op Controleer. Een voorbeeld wordt meteen gecontroleerd zodra je het laadt. De pagina opent met de nepfix al gecontroleerd.

Zo lees je het resultaat

Waar het naar kijkt

Onderdrukkingen: # nosec, # noqa, # type: ignore, usedforsecurity=False, // eslint-disable, @ts-ignore, @ts-nocheck, @SuppressWarnings en #pragma warning disable.

Gevaarlijke patronen: shell=True, verify=False, debug=True, eval( of exec( met een argument dat met een naam begint, zoals een variabele, md5( of sha1(, en een naam die eindigt op password, secret, api_key of token en een waarde tussen aanhalingstekens krijgt van 8 tekens of meer.

Plaatshouders voor weggelaten code: rest unchanged of rest of the code unchanged, rest blijft hetzelfde of rest blijft ongewijzigd, omitted for brevity, implementation here of implementation goes here, en een regel met alleen ....

En of Voor en Na identiek zijn, of alleen in commentaar en witruimte verschillen.

De gevaarlijke patronen volgen Python-syntax (keyword-argumenten, True en False). Code in andere talen krijgt vooral de checks op onderdrukkingen en plaatshouders.

De stempel

Geblokkeerd als minstens één bevinding een hard fail is. Nog open als er geen hard fail is, maar een gevaarlijk patroon uit Voor ook in Na voorkomt. Niet geblokkeerd als geen bevinding een hard fail of waarschuwing is: er is niets gemeld, of een gevaarlijk patroon uit Voor staat niet meer in Na. Geen van de drie zegt dat de code veilig is.

Elke bevinding

Hard fail blokkeert. De wijziging voegde een onderdrukking of een gevaarlijk patroon toe, Na bevat een mogelijke plaatshouder voor weggelaten code, of Voor en Na zijn op commentaar en witruimte na gelijk.

Waarschuwing blokkeert niet: een gevaarlijk patroon dat in Voor stond, komt ook in Na voor, niet vaker dan eerst.

Pass betekent dat een gevaarlijk patroon uit Voor niet meer in Na staat, of dat geen enkele check iets meldde. Een verdwenen patroon laat zien dat de code daar veranderde, niet dat de vervanging klopt.

Hoe het is gevonden

mechanical bij elke bevinding hier. Elke check telt markers, zinsneden of codepatronen in de tekst, of vergelijkt de tekst zonder witruimte, zonder /* */-blokken en zonder alles na # of //, ook binnen strings. Geen enkele check parset de code, dus een patroon in commentaar of in een string telt ook mee. De engine heeft daarnaast bevindingen met parser, uit syntaxbomen, en met tool, uit bandit. Deze pagina heeft geen van beide.

Wat deze pagina niet doet

  • Geen syntaxboom. Deze pagina vergelijkt alleen tekst en patronen. Voor Python-code parset de engine beide versies; welke checks andere talen krijgen, staat onder Vragen op de homepage.
  • Geen externe analyzer. De engine kan bandit twee keer draaien, normaal en met onderdrukkingen genegeerd, om te zien wat een onderdrukking verbergt. Deze pagina kan dat niet.
  • Geen data-flow-analyse. Onveilige invoer die via een hulpfunctie een gevaarlijke aanroep bereikt, vind je hier niet.
  • Geen beweerde dreiging. Je kunt niet opgeven wat de fix zegt te repareren, dus een gevaarlijk patroon dat blijft staan is hier alleen een waarschuwing. De engine blokkeert het als je de dreigingsklasse meegeeft met --claimed-threats, zoals in stap 2 onder Gebruik.
  • Geen check op afgebroken code. Is Na afgebroken, dan staat een patroon uit het ontbrekende deel als verwijderd, met een Pass. Deze pagina weigert alleen een leeg vak. De engine blokkeert een leeg resultaat en waarschuwt als de uitvoer afgebroken lijkt.
  • Commentaar wordt op patroon herkend. Alles na # of // telt als commentaar, ook binnen een string zoals een URL. Een echte wijziging daar kan worden gemeld als alleen commentaar of witruimte.
  • Grove patroonchecks. Elke aanroep van md5( of sha1( telt, ook voor een bestandschecksum; de eigen check van de engine meldt ze alleen bij wachtwoordgegevens. De check op geheimen kijkt alleen naar het einde van de naam en de lengte van de waarde; de engine splitst de naam daarnaast in woorden en slaat waarden over die een URL, e-mailadres of getal met punten (zoals een versie) zijn.

Voor de checks van de engine draai je hem op je eigen machine:

pip install saikou
saikou verify before.py after.py --claimed-threats injection

Vervang injection door de dreigingsklasse die je fix zegt te repareren. Voor de bandit-stap (alleen Python) installeer je met pip install "saikou[analyser]" en voeg je --analyser toe. Of gebruik de agent code-hardener in Claude Code. Meer manieren om het te draaien.
