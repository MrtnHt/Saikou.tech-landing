Being rebuilt

Prove that a security fix is real, not just claimed.

Saikou is becoming an open-source tool that compares code before and after a claimed security fix and blocks the changes that only look hardened - new nosec comments, sanitised values nobody uses, partial fixes, dropped code. No score, no guarantees, just what was checked and how.

The earlier “Model10” service and the claims made for it are being retired. Nothing on this site depends on it, and those claims no longer apply.

Want to follow along, or have a use for it? ceo@saikou.tech

Wordt herbouwd

Bewijs dat een beveiligingsfix echt is, niet alleen beweerd.

Saikou wordt een open-sourcetool die code vóór en ná een beweerde beveiligingsfix vergelijkt en wijzigingen blokkeert die alleen lijken te beveiligen — nieuwe nosec-commentaren, opgeschoonde waarden die niemand gebruikt, halve fixes, weggelaten code. Geen score, geen garanties, alleen wat is gecontroleerd en hoe.

De eerdere “Model10”-dienst en de beweringen daarover worden uitgefaseerd. Niets op deze site hangt ervan af en die beweringen gelden niet meer.
