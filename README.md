# saikou.tech

The source of the page at https://saikou.tech, served by GitHub Pages. This repository holds only that
static page: no scripts, fonts or trackers from other sites.

**English.** Saikou is becoming an open-source tool that compares code before and after a claimed
security fix and blocks the changes that only look hardened. No score, no guarantees: just what was
checked and how.

The earlier "Model10" service is being retired. The claims this README used to make for it no longer
apply, and nothing on the site depends on it.

**Nederlands.** Saikou wordt een open-sourcetool die code vóór en ná een beweerde beveiligingsfix
vergelijkt en wijzigingen blokkeert die alleen lijken te beveiligen. Geen score, geen garanties: alleen
wat is gecontroleerd en hoe.

De eerdere "Model10"-dienst wordt uitgefaseerd. De beweringen die deze README daarover deed, gelden niet
meer, en niets op de site hangt ervan af.

Contact: https://saikou.tech
