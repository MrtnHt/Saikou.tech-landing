# saikou.tech

The source of the site at https://saikou.tech, served by GitHub Pages. This repository holds only
that static site, in English and Dutch: no scripts, fonts or trackers from other sites. It is built
from `site/` in https://github.com/SuperfastSimon/saikou.

**English.** Saikou is an open-source tool that compares code before and after a claimed security
fix and blocks the changes that only look hardened. No score, no guarantees: just what was checked
and how. Install it with `pip install saikou`; the source is at
https://github.com/SuperfastSimon/saikou.

The earlier "Model10" service is retired. The claims this README used to make for it no longer
apply, and nothing on the site depends on it.

**Nederlands.** Saikou is een open-sourcetool die code vóór en ná een beweerde beveiligingsfix
vergelijkt en wijzigingen blokkeert die alleen lijken te beveiligen. Geen score, geen garanties:
alleen wat is gecontroleerd en hoe. Installeren gaat met `pip install saikou`; de broncode staat op
https://github.com/SuperfastSimon/saikou.

De eerdere "Model10"-dienst is uitgefaseerd. De beweringen die deze README daarover deed, gelden niet
meer, en niets op de site hangt ervan af.

Contact: https://saikou.tech
